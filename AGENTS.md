# Project instructions

## Lessons

- This project is standard-library-only Python, verified with Python 3.12.3. Run from the repository root with `python3 -m oversold`; verify numerical and date policy behavior with `python3 -m unittest discover -s tests -v`. This host has no bare `python` alias; keep portable workflow/smoke commands on `python3`.
- 931743 is the CSI Semiconductor Material & Equipment Thematic Index, not an individual equity or an ETF. Eastmoney identifies it as `2.931743`; do not substitute an ETF or total-return index.
- The usable runtime data source is `https://www.csindex.com.cn/csindex-home/perf/index-perf`, with `indexCode/startDate/endDate`. In this environment Eastmoney reader access succeeded but direct Python/curl requests were disconnected; successful tool-reader access alone does not prove application access.
- CSI's chart endpoint can prepend a non-trading `startDate` observation: a request beginning 2024-01-01 returned that holiday with the next session's OHLC. Start initial history on verified session 2023-07-19 and incremental history on an actual cached session. Do not infer trading days from weekdays or deduplicate by equal prices. The 776 dates from this initial start matched the independently observed Eastmoney history.
- CSI `tradingVol` is shares and `tradingValue` is in 100-million-CNY units, rounded to 0.01 of those units. Some CSI/Eastmoney OHLC values differ by 0.01 index point; use one source consistently.
- Default oversold is now Wilder RSI(14) < 30 OR close < Bollinger(20, 2) lower band, after both indicators warm up. The band comparison is strictly less-than so a flat zero-width band does not trigger. Population standard deviation is ddof=0. Seed Wilder with the first 14 gains/losses; compute indicators and entry transitions over full history before trimming two calendar years. Signal.trigger_reason is exported to HTML, CSV, JSON, and CLI output.
- All close policies use Asia/Shanghai. Exclude today's bar before 15:30; scheduled checks run weekdays at 18:00. Missing today's bar is not a negative signal, and offline cached data must remain explicitly offline.
- systemd `ExecStart` arguments support quoting, but a quoted `WorkingDirectory` was rejected as a non-absolute path by systemd 255. Emit the absolute directory without surrounding quotes; escape percent specifiers. Check timer activity explicitly before reporting installation success, then smoke-run the service.
- Generated `data/` and `reports/` are local artifacts ignored by version control. The HTML report embeds all data and chart code; it must keep working through `file://` without a CDN or a server. Local preview servers bind to 127.0.0.1 only.
- On the verified 2024-09-28 through 2026-09-28 window, removing the Bollinger gate alone still gave only 3 RSI<30 days. The relaxed either-indicator rule gives 17 signal days and 9 entries; recalculate entry transitions rather than reusing the old rule's entry dates. Signal frequency is not evidence of improved trading performance.
- GitHub currently redirects the old `Recursive-Self-Improving/aai-oversold` remote to `Recursive-Self-Improving/931743-oversold`; the default branch is `master`, not `main`. Keep workflow push filters aligned with the actual default branch.
- `.github/workflows/daily-report.yml` runs at 10:00 UTC on weekdays (18:00 Shanghai), on `master` pushes, and by manual dispatch. It fetches full history into a fresh runner-temp database and uploads only `reports/` through the official Pages artifact/deployment actions. Keep bash pipefail when teeing CLI output; a failed fetch must block deployment. Pages must use the GitHub Actions publishing source, and public-repository schedules can be disabled after 60 days without repository activity. Local smoke verification is not evidence of a successful remote Pages deployment.
- The report's HTML security boundary is `render_html` escaping `<`, `>`, `&`, U+2028, and U+2029 in serialized JSON before embedding it in `script[type="application/json"]`; DOM rendering uses `textContent` and fixed SVG element/attribute names. Preserve both protections: an inert script MIME type alone does not prevent a literal `</script>` from ending the element. The displayed source URL is text, not a navigable link.
- The redesigned report remains in `oversold/report.py`'s self-contained `_PAGE` template. Its three-month chart fits the container; longer windows retain a minimum candle spacing and scroll. HTML signal rows are newest-first; CSV exports remain chronological. SVG candles use one roving Tab stop plus ArrowLeft/ArrowRight/Home/End over actual recorded sessions, not calendar weekdays (the session before 2026-09-28 is 2026-09-24 in the verified data).
- Browser verification on this ARM64 host can use the cached Playwright `chrome-linux-arm64/chrome`; the default Chrome-for-Testing downloader has no Linux ARM64 build. Missing browser libraries and Noto CJK fonts can be unpacked into a temporary directory and selected with `LD_LIBRARY_PATH` / `FONTCONFIG_FILE`, without changing application dependencies or requiring sudo. Verify Chinese glyphs in screenshots, not just DOM text.
