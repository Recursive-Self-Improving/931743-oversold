# 931743 超卖观察

获取 **中证半导体材料设备主题指数（931743）** 的真实日线 OHLC，收盘后计算超卖状态，列出过去两个日历年中的全部超卖日及首次触发日。提供命令行、SQLite 缓存、CSV/JSON 和可离线打开的交互 K 线 HTML 报告。

Python 3.10+，仅标准库，无须 pip 安装、API Key、数据库服务或前端构建。已在 Python 3.12.3 / Linux 上运行验证。

## 运行

在项目根目录执行：

```bash
python3 -m oversold
```

首次获取 2023-07-19 起的完整日线；后续重取缓存中最后 20 个交易日起的行情，按交易日期覆盖修订值并追加新记录。指标始终使用完整缓存历史计算，再裁剪两年窗口，不会因每次窗口滚动而重新初始化 RSI。

终端打印最新状态和所有信号日期，同时生成：

| 路径 | 内容 |
| --- | --- |
| `data/931743.sqlite3` | 全量 OHLC、成交量、成交额及最近成功抓取时间 |
| `reports/index.html` | 日 K 线、布林带、RSI、超卖标记、日期列表 |
| `reports/daily.csv` | 两年窗口内每个交易日的 OHLC 和指标 |
| `reports/signals.csv` | 所有满足超卖条件的交易日 |
| `reports/entries.csv` | 每段连续超卖的首次触发日 |
| `reports/summary.json` | 数据状态、参数、最新判断和全部报告数据 |

直接在浏览器打开 `reports/index.html`，不需要联网加载 JS/CDN。图表可切换近三个月、一年、两年；悬停、点击或键盘选中 K 线查看当日数据。长区间和手机上的图表、表格可横向滚动。

如需本机 HTTP 预览：

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory reports
```

访问 `http://127.0.0.1:8000/`。云主机使用 SSH 端口转发，不要直接把开发预览端口暴露到公网。

### 历史截止日和离线分析

```bash
# 截止指定日期，不使用此后日线；默认输出 reports/2025-12-31/
python3 -m oversold --as-of 2025-12-31

# 不联网；报告明确标为离线，默认输出 reports/offline/
python3 -m oversold --offline

# 自定义缓存和输出目录
python3 -m oversold --db data/931743.sqlite3 --output reports/custom
```

`--as-of` 不可晚于北京时间今天。网络失败会非零退出，不会悄悄使用缓存声称今日更新成功；旧报告可能仍在，须检查生成时间。只有显式 `--offline` 才离线分析。截止日早于可用历史或预热不足时会报错或给出覆盖警告，不把不完整历史描述为完整两年结果。

## 超卖规则

同一已收盘交易日同时满足：

```text
RSI(14) < 30
且
收盘价 <= 布林带下轨(20, 2)
```

- **RSI**：Wilder 平滑。用最初 14 次收盘变动的上涨/下跌均值初始化，此后分别计算 `(上一均值 × 13 + 当日涨/跌幅) / 14`。涨跌均为零时 RSI=50，仅上涨时为100，仅下跌时为0。这里的涨跌幅是点数差，不是百分比。
- **布林带**：包括当日的最近20个收盘价，`中轨 = 均值`，`下轨 = 均值 − 2 × 总体标准差`，`上轨 = 均值 + 2 × 总体标准差`；`ddof=0`。
- 使用未四舍五入的计算值判定；展示值会四舍五入。
- 前14根没有 RSI，前19根没有布林带，指标不齐不发信号。
- `oversold=True`：当日满足两个条件。
- `entry=True`：当日超卖，前一个已记录交易日未超卖；先计算转入状态，再裁剪窗口，避免窗口第一天被误报为新触发。
- “过去两年”按请求截止日向前减两个日历年，两端包含，不是固定504根日线；2月29日对应起点2月28日。数据延迟时不会把窗口整体向过去挪动。

这是一条较严格的组合规则，不等同于仅看 RSI<30。不同平台的 RSI 初始化/平滑方法、标准差口径和源价格可能不同。只使用当日及此前的价格，不使用未来价格；历史数据仍是提供方当前返回的版本，并非历史发布时点数据库。

## 收盘和交易日口径

- 所有判断使用 `Asia/Shanghai`，不依赖服务器本地时区。
- 北京时间 **15:30 前排除当天 K 线**，避免把盘中波动认作收盘信号；15:30 是收盘后的缓冲时间，不代表数据源承诺此时必然发布。
- 只对数据源实际返回的日线判断，不自行补周末或节假日。
- 若没有当天日线，明确显示“可能休市或源数据未发布”，只展示最新可用日期，**不显示成今天没有超卖**。项目不额外维护交易所节假日日历，因而不区分这两种原因。
- `current`、`awaiting_close`、`no_current_bar`、`historical`、`offline` 分别表示当日已获取、等待收盘、缺少当日日线、历史回溯、离线缓存。

## 每日自动运行

Linux/systemd 用户会话中执行：

```bash
python3 scripts/install_timer.py
```

安装并启用用户级 `oversold-931743.timer` 与 `oversold-931743.service`，固定在 **周一至周五北京时间18:00** 运行，服务器为 UTC 也不影响。节假日仍会运行一次，但没有真实日线就不会生成虚假的当日判断。定时任务不负责下单、邮件或消息推送，结果落入报告文件与 systemd 日志。

安装器把当前仓库和 Python 的绝对路径写入用户 unit；移动仓库后需重新执行安装器。机器必须运行且能联网，接口失败会在日志中显示失败，不作静默降级。

```bash
# 查看下一次执行时间（systemctl 可能按服务器时区显示）
systemctl --user list-timers oversold-931743.timer

# 手动执行与定时器相同的任务
systemctl --user start oversold-931743.service

# 查看执行结果和日志
systemctl --user show oversold-931743.service -p Result -p ExecMainStatus
journalctl --user-unit=oversold-931743.service -n 60 --no-pager

# 停止自动运行，不删除日线或报告
systemctl --user disable --now oversold-931743.timer
```

退出登录后继续调度需要用户启用 linger，可用 `loginctl show-user "$USER" -p Linger` 检查；必要时由管理员执行 `loginctl enable-linger "$USER"`。不支持 systemd 的环境仍可运行单次命令，并由已有调度器在北京时间18:00调用它。

## 数据来源与限制

- 标的说明：[中证官方事实说明书](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/931743factsheet.pdf)。931743 是指数，不是单只股票，也不是可直接交易的证券。
- 实际抓取：[中证官方公开行情接口](https://www.csindex.com.cn/csindex-home/perf/index-perf?indexCode=931743&startDate=20230719&endDate=20260928)，字段包括 `tradeDate/open/high/low/close/tradingVol/tradingValue`。不使用 ETF 价格代替指数，不混用全收益指数。
- OHLC 单位为指数点；成交量保存为股；成交额由源字段“亿元”转换为元，但原始精度只有0.01亿元。
- 官网接口属于公开网页使用的接口，可能延迟或变化，没有本项目可保证的可用性承诺。
- 实测请求起点是非交易日时，接口可能插入起点日期的图表补点。因此首次从已与[东方财富 2.931743](https://quote.eastmoney.com/q/2.931743.html)核对的真实交易日2023-07-19取数，增量请求也从缓存中的真实交易日起发起，不把任意日历日当作起点。
- 核对过的776个交易日期一致，但部分 OHLC 与东方财富有0.01点差异；本项目始终以中证源为准，不混合两套价格。东方财富的 Python 直连在验证环境中被断开，未用作运行时备用源。
- 重叠更新会获取最近20个交易日的修订；更早修订不会自动重抓。需要全量重建时，可使用新的 `--db` 路径。

## 代码结构

- `oversold/data.py`：官方行情、字段约束、SQLite 与增量更新。
- `oversold/indicators.py`：Wilder RSI、布林带、超卖和首次触发。
- `oversold/app.py`：收盘口径、日期窗口、报告与导出。
- `oversold/report.py`：无外部依赖的 HTML/SVG 交互图表。
- `oversold/__main__.py`：命令行入口。
- `scripts/install_timer.py`：用户级每日定时任务安装。
